# Pictures & videos

Put your pictures and videos here. A folder per month keeps it tidy:

```
media/
  month1/cover.jpg
  month1/first-call.mp4
  month2/...
```

Then list them in `index.html` under that month's `photo`, `video` and `gallery`.
Use .jpg/.png/.webp for pictures and .mp4 for videos. GitHub won't take
files over 100 MB, so keep videos short.
